02 · Run locally

Use your application’s own tests.

  1. Extract the toolkit and copy config.example.json outside its folder.
  2. Identify your release, list files with expected hashes, and connect your own test commands. Missing adapters stay blocked.
  3. Run the preflight below. Add --execute once you have reviewed the configured commands and their effects.
python /path/to/toolkit/run_tests.py --profile general --config system.json --system-root /path/to/system --output general-report.json

File checks compare bytes. Command checks use your adapter’s assertions and exit code. They run with your local permissions; use a disposable software environment and adapters that clean up their services.

What these results establish

A recorded pass applies to the identified check and release. Document checks establish presence and matching bytes; a reviewer still needs to assess the contents. Local software results cannot close official program acceptance, supply-chain assessment, organizational certification or physical testing.

The Gauntlet profile inventories selected public document requirements. The DoW profile uses selected SSDF practices; applicability comes from your contract. Neither profile is the complete official requirements suite, and this page issues no certification.
