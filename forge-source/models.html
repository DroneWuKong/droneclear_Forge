Use the right file

The formats contain the same learned detector. They are different packaging for different software—not evidence of separate training runs.

.onnx
Start here for inference

Most agnostic option. Use with ONNX Runtime, OpenCV DNN, compatible converters, or other ONNX-capable runtimes.

.pt
Train or fine-tune

YOLOv5/PyTorch checkpoint for compatible code. Python checkpoints can execute code when loaded; use only in a trusted environment.

.tflite + labels
Edge/APB bench work

Small INT8 graph for TensorFlow Lite. The labels, preprocessing, anchors, output decoding, and accelerator support are part of its contract.
