Data API

Every dataset behind this site is readable as JSON from one endpoint — GET /api/data?type=<dataset> — no key required. The same data that renders the flags board, the daily brief, and the lens pages, refreshed by the PIE pipeline every day at 11:30 UTC.

Endpoint
GET https://uas-patterns.com/api/data?type=pie_brief

Response envelope (HTTP 200):

{
  "data":  { …dataset payload… },
  "type":  "pie_brief",
  "tier":  "free",
  "source": "static"   // present only when served from the static fallback
}

Datasets are served from Cloudflare KV (written by the daily pipeline); if a dataset missed the last sync, the worker falls back to the static copy bundled with the deployment and marks it "source": "static". Errors: 400 missing type (the body lists all available datasets), 404 unknown or unavailable dataset. CORS is open (Access-Control-Allow-Origin: *) — you can call this from a browser app.

Fair use & interpretation The API is free for research, journalism, and internal tooling — cache responses (data changes once daily; there is no need to poll more than hourly) and attribute uas-patterns.com when you republish. Risk labels are analytic signals, not allegations; before acting on a flag, read what its confidence score actually means in the estimative-language reference and the methodology at uas-handbook.com. Schemas are stable but unversioned; breaking changes will be announced in the brief.
